# Notes

Use this folder for:

- rough captures of user ideas
- conversation summaries
- unresolved design questions
- design tradeoff notes

## Rules

- Use `../templates/design-note-template.md` for system notes.
- A system note is the only live primary doc for that system while it is still at note maturity.
- Do not create duplicate notes for the same `system_id`.
- If the system already has a live feature or requirement doc, update that higher-tier doc instead of creating a note.
- When a note is promoted to `features/`, migrate all useful content into the feature doc and delete the note.

See `../DOC_LIFECYCLE.md`.
