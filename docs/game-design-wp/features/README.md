# Features

Use this folder for feature drafts that are not yet implementation-ready.

## Rules

- Use `../templates/feature-draft-template.md` for feature drafts.
- A feature draft is the only live primary doc for that system while it is at feature maturity.
- Do not keep the source note after promotion; migrate it into the feature doc and delete it.
- Do not create duplicate features for the same `system_id`.
- If the system already has a live requirement doc, update that requirement doc instead of creating a feature.
- When a feature is promoted to `requirements/`, migrate all useful content into the requirement doc and delete the feature.

See `../DOC_LIFECYCLE.md`.
