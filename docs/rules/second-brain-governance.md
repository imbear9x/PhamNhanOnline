# Second Brain Governance

## Core policy

- canonical project memory lives in repo `docs/`
- docs-first, code-verified
- preserve legacy docs during migration
- create conflict reports instead of silently forcing agreement
- use small, traceable updates

## Ownership

- `dev` owns implementation truth and code changes
- `gamedesign` owns evolving gameplay design artifacts in `docs/game-design-wp/`
- `knowledge-manager` owns documentation stewardship, audits, and knowledge hygiene
- `devops` may bootstrap and maintain the agent/runtime side of the knowledge system

## Status rule

Only mark docs `verified` after evidence-based checking.
